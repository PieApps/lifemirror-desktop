## 1. Executive Vision & Core Constraints

LifeMirror Desktop is a privacy-first, local-focused productivity reflection application that transforms continuous 24/7 operating system activity logs into a beautiful, serpentine infographic ("S-Curve" timeline).

### Crucial Constraints for AI Agents:

* 
**Data Isolation:** 100% Local Storage via an encrypted SQLite database. **No external Cloud API servers allowed** except for fetching basic application branding metadata icons locally cached.


* 
**Localized AI:** Summaries must be driven exclusively via locally executed Large Language Models (e.g., Llama/Ollama integration via native bindings).


* 
**Tech Stack Hardline:** Tauri 2.0 (Rust Core) paired with a modern Frontend Framework (React/Svelte/Vue) using Tailwind CSS and Framer Motion / D3.js for SVG-based timeline rendering.

## 5. Engineering Challenges & Technical Implementations

### Challenge 1: The Raw Data Noise Chaos (Micro-Task Spikes)

* 
**The Problem:** High-frequency window toggles (e.g., selecting a Slack alert for 3 seconds) pollute database logs, ruining the smooth layout flow of the visual timeline.


* 
**Local-First Architecture Solution:** Implement a **Time Threshold Aggregator Engine** inside the SQLite collection pipeline.


$$T_{\text{session}} = \sum (t_{\text{end}} - t_{\text{start}}) \ge 120\text{ seconds}$$


Any window state alteration lasting less than 120 seconds is automatically filtered out or merged into an active parenting task group (e.g., matching a VS Code session with a brief StackOverflow lookup).



### Challenge 2: Mathematical Complexity of the Responsive S-Curve SVG Path

* 
**The Problem:** Rendering a dynamic, infinitely scrolling serpentine vector graphic layout that remains responsive without degrading rendering performance.


* 
**Local-First Architecture Solution:** Use a continuous cubic Bézier curve mathematical formulation generated programmatically inside the frontend layout framework.



```javascript
// Dynamic S-Curve Path Generation Logic for the Frontend Agent
function generateSCurvePath(dataNodes, rowHeight = 200, width = 600) {
  let d = `M ${width / 2} 0`; // Start at the middle top
  dataNodes.forEach((node, index) => {
    const yStart = index * rowHeight;
    const yEnd = (index + 1) * rowHeight;
    const isEven = index % 2 === 0;
    
    // Calculate sweeping control coordinates for the serpentine flow
    const cpX1 = isEven ? width : 0;
    const cpX2 = isEven ? width : 0;
    
    d += ` C ${cpX1} ${yStart + rowHeight/4}, ${cpX2} ${yEnd - rowHeight/4}, ${width / 2} ${yEnd}`;
  });
  return d;
}

```

### Challenge 3: Secure, Zero-Latency Context Isolation

* 
**The Problem:** Managing sensitive text logs, inline journaling, and app tracking histories locally without draining the user's desktop hardware resources.


* 
**Local-First Architecture Solution:** * Deploy **SQLCipher** with AES-256-GCM hardware-accelerated page-level database encryption.


* The decryption key is safely derived dynamically from the host OS's native secure storage vault (e.g., Apple Keychain or Windows Credential Manager) via Tauri's native platform API wrappers.
* Run the local inference loop at low priority (`nice` or low-priority thread scheduling profiles in Rust) to perform local AI daily summary generation only when user idle state thresholds exceed 10 continuous minutes.
